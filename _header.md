# Corporate Line of Business (LoB) ChatBot

**Status: Proposed / unimplemented.** This repository contains the generic
Avm.Authoring Terraform starter, which creates a virtual network. It does not
implement the advertised Azure OpenAI and Cognitive Search pattern and is not
ready for service deployments.

The obsolete, nonfunctional AzureRM template has been replaced with the AzAPI
starter. Its placeholder interfaces are not retained; the starter requires
`address_space`, `location`, `name`, and an existing resource group's `parent_id`.
